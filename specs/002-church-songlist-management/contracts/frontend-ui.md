# Frontend UI Contract — Church Songlist Management

This document is the contract for the frontend's externally-visible surface:
the **routes** the user can navigate to, the **components** that compose them
(by atomic-design tier), and the **interfaces** (TypeScript types) that connect
the frontend to the backend OpenAPI defined in `./openapi.yaml`.

The contract is intentionally implementation-light — it specifies *shape* and
*responsibility*, not internal mechanics.

---

## 1. Route map (Next.js 16 App Router)

| Path | Visibility | Render mode | Purpose | Drives FRs |
|---|---|---|---|---|
| `/` | Public | Server Component | Catalog list (search + filter), default view | FR-022, FR-023, FR-024, FR-027, FR-031 |
| `/songs/[id]` | Public | Server Component | Song detail | FR-025, FR-026, FR-031 |
| `/admin` | Admin / Super Admin | Server Component (auth-gated) | Admin landing (links to song / taxonomy / fields) | FR-004 |
| `/admin/songs/new` | Admin / Super Admin | Client Component (form) | Create song | FR-008, FR-009 |
| `/admin/songs/[id]/edit` | Admin / Super Admin | Client Component (form) | Edit song | FR-011, FR-030 |
| `/admin/taxonomies/[kind]` | Admin / Super Admin | Mixed (RSC list + Client editor) | Manage Seasons / Masses / Special Events | FR-017, FR-019 |
| `/admin/optional-fields` | Admin / Super Admin | Mixed | Manage optional field definitions | FR-018, FR-019 |
| `/super-admin/users` | Super Admin only | Mixed | Promote / demote users | FR-005, FR-006 |
| `/sign-in`, `/sign-up` | Public | Provided by Clerk | Authentication entry | FR-001 |

Auth gating is enforced by `middleware.ts` via `clerkMiddleware` + `createRouteMatcher`. Role checks (Admin vs Super Admin) happen in Server Components by reading `auth()` and the local `/api/v1/auth/me` role.

## 2. Atomic-design component map

All components are **TypeScript-typed**. "Dumb" components receive every value as a prop and never read context, perform fetches, or call mutations. They are reusable across pages.

### 2.1 `components/ui/` — ShadCN primitives (do not edit)
- `Button`, `Input`, `Label`, `Select`, `Checkbox`, `Dialog`, `AlertDialog`, `Card`, `Badge`, `DropdownMenu`, `Sheet`, `Skeleton`, `Toast`, `Tooltip`, `Form` (with `react-hook-form`).
- Generated by `pnpm dlx shadcn@latest add <name>`.

### 2.2 `components/atoms/`
| Atom | Props (essential) | Notes |
|---|---|---|
| `LinkButton` | `href`, `variant`, `children` | Wraps `Button` + `next/link` |
| `RoleBadge` | `role: Role` | Visual chip |
| `EmptyState` | `title`, `description?`, `actionSlot?` | Drives FR-028 |
| `ErrorState` | `error`, `onRetry?` | Drives FR-029 |
| `LoadingSkeleton` | `lines?`, `variant?` | |
| `ExternalLink` | `href`, `children` | Always opens in a new tab (FR-026); `rel="noopener noreferrer"` |

All atoms are pure / dumb. `"use client"` only when interactive (e.g., `LinkButton`).

### 2.3 `components/molecules/`
| Molecule | Props | Notes |
|---|---|---|
| `SearchInput` | `value`, `onChange`, `onSubmit`, `placeholder?` | Debounce in parent |
| `FilterChip` | `label`, `selected`, `onToggle` | Used per taxonomy value |
| `TaxonomyFilterGroup` | `kindLabel`, `values: TaxonomyValue[]`, `selectedIds`, `onChange` | Pure |
| `SongCard` | `song: SongSummary`, `href` | List item |
| `OptionalFieldLinkRow` | `field: OptionalFieldValue` | Renders an `ExternalLink` |
| `ConfirmDetachDialog` | `open`, `entityLabel`, `usageCount`, `onConfirm`, `onCancel` | Drives FR-019 |
| `RoleSelect` | `value: Role`, `onChange` | Restricted to `USER`/`ADMIN` (super admin promotion only) |
| `VersionConflictBanner` | `onRefresh` | Surfaces 409 from FR-030 |

### 2.4 `components/organisms/`
| Organism | Behaviour |
|---|---|
| `CatalogList` | Renders the paginated list (RSC); composes `SongCard`s and `EmptyState`. |
| `CatalogFilters` | Composes one `TaxonomyFilterGroup` per kind + `SearchInput`. Client. |
| `SongDetail` | Reads a `SongDetail` object and renders title, composer chips, taxonomy chips, optional-link rows. RSC. |
| `SongForm` | React-Hook-Form + Zod, supports both create and edit. Client. |
| `TaxonomyValueEditor` | Inline rename / delete with `ConfirmDetachDialog`. Client. |
| `OptionalFieldEditor` | Same shape for optional-field definitions. Client. |
| `UserRoleTable` | Lists users + `RoleSelect`; refuses last-Super-Admin demotion in UI before submit (FR-006 defence-in-depth). Client. |

### 2.5 `components/templates/`
- `CatalogPageLayout` — header, filter sidebar slot, content slot, mobile-first responsive (FR-027).
- `AdminPageLayout` — sidebar with admin sections; gated by role.

## 3. Type contract (`frontend/types/`)

The frontend mirrors the OpenAPI schema exactly. Types are generated (or hand-typed and unit-tested for parity) into `frontend/types/api.ts`. Example shape:

```ts
export type Role = "SUPER_ADMIN" | "ADMIN" | "USER";

export interface UserAccount {
  id: string;
  email: string;
  display_name: string | null;
  role: Role;
  created_at: string;
  updated_at: string;
  version: number;
}

export interface Composer {
  id: string;
  name: string;
}

export type TaxonomyKind = "SEASON" | "MASS" | "SPECIAL_EVENT";

export interface TaxonomyValue {
  id: string;
  kind: TaxonomyKind;
  name: string;
  version: number;
  created_at: string;
  updated_at: string;
}

export interface OptionalFieldDefinition {
  id: string;
  label: string;
  kind: "LINK";
  version: number;
  created_at: string;
  updated_at: string;
}

export interface OptionalFieldValue {
  definition_id: string;
  label: string;
  value_url: string;
}

export interface SongSummary {
  id: string;
  title: string;
  composers: Composer[];
  seasons: TaxonomyValue[];
  masses: TaxonomyValue[];
  special_events: TaxonomyValue[];
  version: number;
}

export interface SongDetail extends SongSummary {
  optional_fields: OptionalFieldValue[];
  created_at: string;
  updated_at: string;
}

export interface Page<T> {
  items: T[];
  page: number;
  page_size: number;
  total: number;
}

export interface ApiError {
  error: { code: string; message: string; details?: Record<string, unknown> };
}
```

## 4. Service-layer interfaces (`frontend/services/api/`)

Per Constitution Principle II ("favour interfaces"), the frontend API client is exposed as **interfaces**, not concrete classes. Implementation is a typed `fetch` wrapper that injects the Clerk Bearer token via `await auth().getToken()` (server) or `useAuth().getToken()` (client). The interfaces are what consumer code imports.

```ts
// frontend/services/api/contracts.ts

import type {
  SongSummary, SongDetail, Page, TaxonomyKind, TaxonomyValue,
  OptionalFieldDefinition, UserAccount, Role,
} from "@/types/api";

export interface SongsApi {
  list(params: {
    q?: string;
    season?: string[]; mass?: string[]; specialEvent?: string[];
    page?: number; pageSize?: number;
  }): Promise<Page<SongSummary>>;
  get(id: string): Promise<SongDetail>;
  create(input: SongWriteInput): Promise<SongDetail>;
  update(id: string, version: number, input: SongWriteInput): Promise<SongDetail>;
  delete(id: string, version: number): Promise<void>;
}

export interface SongWriteInput {
  title: string;
  composers: { name: string }[];
  season_ids?: string[];
  mass_ids?: string[];
  special_event_ids?: string[];
  optional_fields?: { definition_id: string; value_url: string }[];
}

export interface TaxonomiesApi {
  list(kind: TaxonomyKind): Promise<TaxonomyValue[]>;
  create(kind: TaxonomyKind, name: string): Promise<TaxonomyValue>;
  rename(kind: TaxonomyKind, id: string, version: number, name: string): Promise<TaxonomyValue>;
  usage(kind: TaxonomyKind, id: string): Promise<{ usage_count: number }>;
  delete(kind: TaxonomyKind, id: string, version: number, detach: boolean): Promise<void>;
}

export interface OptionalFieldsApi {
  list(): Promise<OptionalFieldDefinition[]>;
  create(label: string): Promise<OptionalFieldDefinition>;
  rename(id: string, version: number, label: string): Promise<OptionalFieldDefinition>;
  usage(id: string): Promise<{ usage_count: number }>;
  delete(id: string, version: number, detach: boolean): Promise<void>;
}

export interface UsersApi {
  list(params: { q?: string; page?: number; pageSize?: number }): Promise<Page<UserAccount>>;
  setRole(id: string, version: number, role: Exclude<Role, "SUPER_ADMIN">): Promise<UserAccount>;
}

export interface AuthApi {
  me(): Promise<UserAccount>;
}

export interface ApiClient {
  songs: SongsApi;
  taxonomies: TaxonomiesApi;
  optionalFields: OptionalFieldsApi;
  users: UsersApi;
  auth: AuthApi;
}
```

A test fake (`frontend/services/api/fake.ts`) implements `ApiClient` against in-memory state and is used by Vitest component tests to honour the same contract.

## 5. Behaviour contracts (cross-cut)

| Area | Contract |
|---|---|
| Empty state | When `items.length === 0` after a search/filter, render `<EmptyState>` (FR-028). |
| Error state | Any thrown `ApiError` from a service surfaces an `<ErrorState>` with retry (FR-029). |
| Concurrency | Edit forms read `version` on mount and submit `If-Match`. On `409 conflict_version`, render `VersionConflictBanner` and offer reload (FR-030). |
| External links | Optional-field link values render with `target="_blank" rel="noopener noreferrer"` (FR-026). |
| Mobile breakpoint | 320px–desktop, no horizontal scroll, tap targets ≥ 44px (FR-027, SC-007). Verified via Playwright at viewports `360×740`, `768×1024`, `1280×800`. |
| Role gating | Routes under `/admin/*` require Admin or Super Admin; `/super-admin/*` requires Super Admin. Middleware redirects unauthenticated → Clerk sign-in; authenticated-but-unauthorised → `/` with toast. |
| Public read | `/`, `/songs/[id]`, taxonomy/optional-field LIST endpoints are reachable without auth (FR-031). |
| First-Super-Admin invariant | `UserRoleTable` disables the demote action for the only `SUPER_ADMIN` (defence in depth — server enforces FR-006 authoritatively). |
